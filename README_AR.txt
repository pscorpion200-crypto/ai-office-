مكتب الذكاء الاصطناعي - نسخة قابلة للنشر

المحتويات:
- واجهة مكتب افتراضي باللغة العربية و8 موظفين/أقسام.
- دردشة منفصلة لكل موظف مع حفظ المحادثات.
- مدير عام يوزع الهدف إلى مهام على الأقسام.
- إدارة المهام وتغيير حالتها وحذفها.
- حماية بكلمة مرور (OFFICE_PASSWORD).
- إعداد نشر على Render مع مساحة تخزين مستمرة، وDocker.

النشر على Render:
1) فك ZIP وارفع الملفات إلى مستودع GitHub خاص.
2) في Render اختر New > Blueprint واربط المستودع الذي يحتوي render.yaml.
3) أدخل AI_API_KEY (مفتاح API من مزود النموذج)، AI_MODEL (اسم نموذج متاح فعلاً بحساب API)، وOFFICE_PASSWORD (كلمة قوية).
4) أكمل النشر. ستعطيك Render رابط الموقع.
5) الدخول: اسم المستخدم office وكلمة المرور التي وضعتها في OFFICE_PASSWORD.

تنبيه: لا يفترض أن اشتراك ChatGPT يوفر تلقائياً مفتاح API أو أن GPT-6 متاح في API؛ اختر نموذجاً متاحاً في حساب API لديك. تكلفة API منفصلة.

تشغيل محلي:
- تحتاج Node.js 18+.
- انسخ .env.example إلى .env واملأ الإعدادات.
- npm install ثم npm start.
- افتح http://localhost:3000 (سيطلب بيانات Basic Auth إن وضعت OFFICE_PASSWORD).

الحدود:
- هذه نسخة تطبيق ويب أولية جاهزة للنشر وليست منصة وكلاء ذات تشغيل تلقائي مستقل 24/7.
- الوكلاء يعملون عند إرسال طلب/تخطيط؛ لا توجد مراسلات بريدية أو PayPal أو تنفيذ معاملات متصل.
- ملفات JSON تحفظ المحادثات والمهام؛ قرص Render المستمر مهيأ في Blueprint.
- لا تستخدمها لتخزين أسرار أو بيانات حساسة دون تطوير أمني إضافي.
